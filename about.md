I'm Eduardo Vieira, a software engineer who likes to know how things
work — which usually means taking them apart.

I've been building things professionally since 2007, working my way
up the stack: electronics and microcontrollers first, then embedded
Linux in C, and these days cloud-hosted web apps in Python.
The constant along the way was never a particular layer — it's
wanting to understand the one underneath.

That itch shows up in my side projects: a
[SNES emulator written in Python](https://github.com/eduardovra/PySNES),
and a [dependency-free ASGI web server](https://github.com/eduardovra/simple-asgi-webserver)
that this blog's [web server series]({{ '/writing-a-python-web-server-from-scratch-part-1-http/' | relative_url }})
takes apart piece by piece.

I write mostly so I don't forget, and publish in case it helps someone
else. Posts come out whenever something is worth writing down — no
schedule, no promises.

If you'd like to get in touch or see what I'm building, I'm on
[GitHub](https://github.com/eduardovra),
[LinkedIn](https://www.linkedin.com/in/{{ site.social-linkedin }})
and [X](https://x.com/{{ site.twitter.username }}).
